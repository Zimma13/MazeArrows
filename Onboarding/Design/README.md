# Maze Arrows — Онбординг · Пакет для разработчика

Хай-фай прототип день-0 онбординга (16 экранов) по `onboarding-spec.md` v1.1.
Это **визуальный референс** для реализации на SwiftUI + SpriteKit, а не продакшн-код.
HTML/React здесь — только чтобы точно показать вёрстку, копирайт и состояния.

## Как открыть
Открой `Maze Arrows - Onboarding.html` в браузере (нужен интернет — React/Babel с CDN).
Экраны разложены на панорамном холсте: тяни мышью, колесо — зум, двойной клик по
карточке — фуллскрин.

## Туториальные доски (нотация §4)
Сетка 6×6, захардкожены как `TutorialLevelDefinition`, обязателен солвер-тест
(unloseable, ацикличный граф блокировок, таргет хинта свободен). В прототипе
координаты в `TUT_LAYOUTS` (onboarding-screens.jsx) — это визуальный слепок; на
проде брать точные тела/направления из §4 спеки.

## Ветвления (см. секции «Ветвления» на холсте)
- **Закрыл пейволл** — авто-старт L4; молча планируется welcome-offer, дедлайн 24ч **от первого показа оффера**.
- **Abandoned txn** — recovery-пейволл «Передумал? Триал всё ещё бесплатный».
- **Реинсталл с премиумом** — пейволл и Premium-подписи выпилены.
- **Офлайн / продукты не загрузились** — пейволл молча скипается, `paywall_products_load_failed`.

## Дизайн-токены
- Шрифты: **Bricolage Grotesque** (дисплей/заголовки/кнопки), **Geist** (UI/текст).
- Тема по умолчанию — **Aurora Light**. Все цвета, тени кнопок и границы — из `themes.jsx`.
- Тайминги (§3): тап <100мс; переходы 250–300мс; celebration 500–800мс, финал ≤1200мс.
- Доступность: Reduce Motion — замена каждого fly-out/shake/burst; Dynamic Type на плашках; iOS 16 floor (спринги back-deployed).

## Что НЕ реализовано в прототипе (по дизайну)
Анимации (морф Photo Maze, slow-mo, конфетти, пульс хинта) показаны статичными
кадрами. Инструментация событий `ob_*`, A/B-сплиты и StoreKit — см. §6–§8 спеки.

Полная спецификация и источники: `onboarding-spec.md`, `onboarding-research-raw.md`.
