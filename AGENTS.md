# Инструкции проекта

## Версия 2

- Все изменения, относящиеся к версии 2, записывать в `VERSION_2.md`: результат для игрока, выполненные проверки и оставшиеся ограничения. Этот файл служит основой будущего описания «Что нового».
- Отделять реализованное от планов; не записывать непроверенное как проверенное.
- При продолжении кампании сохранять исходные уровни 1–240, их ID, правила и прогресс игроков. Новая глава 241–260 хранится отдельно в `levels-v2.json` и использует `rulesVersion: 2`.

## Локализованные ролики и скриншоты

- Хранить один набор на уникальную языковую версию. Не дублировать одинаковые файлы для региональных локалей; соответствие локалей общему набору указывать в манифесте.
- Отдельные файлы создавать только при реальных различиях перевода, изображения или технических требований размещения.
