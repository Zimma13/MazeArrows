# Каталог текущей графики предметов

Дата: 16 октября 2026. Один общий набор с русскими подписями — `ru/`. Региональные копии не создаются.

Изображения получены непосредственно из `ObstacleNode` и `ArrowPieceNode` через SpriteKit на QA-симуляторе iOS 26.4. Тема — Midnight Neon, стандартный контраст, без контура стрелок. Объекты увеличены для рассмотрения; форма стрелки в каталоге прямая, а на уровнях она может изгибаться. Компоновка карточек и подписи предназначены для каталога, а не для игрового интерфейса.

- [Ворота и ключи версии 2](ru/01-gates-v2.png): обе группы, закрытое и открытое состояния. Используются на 241–260.
- [Препятствия-заготовки](ru/02-obstacle-prototypes.png): стена, старые ворота-фильтр, разрушаемый блок, портал, ледяная плитка и пружина. В текущей кампании отсутствуют. У портала, ледяной плитки и пружины телепортация, скольжение и отскок ещё не реализованы.
- [Стрелки исходной кампании](ru/03-campaign-arrows.png): обычная, замороженная, два состояния хрупкой, старый ключ и стрелка-замок.
- [Стрелки-заготовки](ru/04-arrow-prototypes.png): тяжёлая, двунаправленная, бомба и связанная стрелка; вне текущей кампании.

Старый ключ с номером открывает стрелку-замок с тем же номером. Новые ключи ○/◇ открывают клетки ворот соответствующей группы. Ворота-фильтр со стрелкой — отдельное старое препятствие, ключом не открываются.

Внешность показана без художественной правки: например, бомба в этой теме действительно тёмная, а некоторые старые значки очень маленькие. Генеративная перерисовка не использовалась. Игровой код, уровни и сохранения при подготовке каталога не изменялись; временный экспортёр удалён после получения изображений.
