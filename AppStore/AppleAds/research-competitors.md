Поэтому одно обещание «расслабляющая логическая игра» слабо отличает новинку. У нашего приложения более конкретный набор: комбо, 240 уровней, Daily, Zen и Photo Maze. ## Практическое решение для $100/месяц

1. Основной тест — одна витрина, Search Results, небольшой список наиболее буквальных exact-запросов. Для English-кластера кандидаты: `arrow puzzle`, `arrow escape`, `arrows puzzle`, `arrow maze`, `arrow out`, `arrow untangle`. Окончательно включать после проверки Apple Ads; существование слов в конкурентной карточке не гарантирует impressions.
2. Отложить дорогие по широте намерения `puzzle games`, `brain games`, `games`, `logic games`, `maze games`: они охватывают разные механики. Это решение по релевантности и размеру бюджета, а не утверждение измеренной высокой ставки.
3. `tap away`, `tap out`, `untangle puzzle`, `arrows jam puzzle` — вторая волна с контролируемой долей бюджета. Конкретные бренды `arrowscapes`, `point out`, `redirect it` не нужны в первом тесте; они усложняют интерпретацию намерения.
4. Отделять слово `arrow` от стрельбы и аркад. Кандидаты на negatives после проверки реальных поисковых фраз: archery, bow, crossbow, arrow fest, io, 3d. Не добавлять чрезмерно широкие исключения без просмотра их эффекта.
5. Визуальное обещание: показать одну очевидную свободную стрелку и результат освобождения пути; далее Daily/Zen и Photo Maze. Не обещать тысячи уровней при 240 уровнях кампании. Не делать медицинских заявлений об улучшении мозга.
6. Проводить оценку по search term → tap → install → первому содержательному игровому событию → покупке. Малый CPI сам по себе не показывает окупаемость подписного продукта.
