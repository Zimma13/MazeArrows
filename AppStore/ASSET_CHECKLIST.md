# Материалы App Store для нативной версии 2.0

- Метаданные для витрин и описание комплекта содержатся в [ASO](ASO/README.md).
- Для iPhone и iPad использовать реальные экраны платной сборки. Общие кадры и ролики загружать повторно из одного языкового комплекта для всех подходящих регионов. Порядок сборки и соответствие материалов витринам — в [ScreenshotSources](ScreenshotSources/README.md).
- Для проверки Apple подготовить инструкции по кампании, Zen и Photo Maze. Исторические иллюстрации подписки относятся к 1.x и используются при обслуживании прежних пользователей.
- Иллюстрации уже существующих достижений находятся в [GameCenter/Achievements](GameCenter/Achievements).
