## App Review Notes

Готовый английский текст для черновика обновления.

```text
This is version 2.0 of the existing Arrow Maze game. The paid download includes the 260-level campaign, Photo Maze, Zen, hints where the game mode allows them, and all visual themes. Advertising and the subscription purchase screens have been removed. Existing owners receive the same base game in the update.

Start from the main menu and tap Play. The campaign unlocks progressively. Signal Gates is the eighth chapter, with 20 levels following level 240. In this chapter, moving a key arrow off the board opens gates with the same symbol.

From the main menu open Photo Maze, pick a photo, adjust its silhouette or detail, then tap Play. There is no allowance to replenish. For unlimited generated boards, choose Zen and continue after a win. There are no level packs for sale in this version.
```

Цена загрузки задаётся отдельно в App Store Connect. Предыдущие подписки управляются по существующим идентификаторам, а обе группы пользователей получают функции непосредственно из новой базовой игры.
